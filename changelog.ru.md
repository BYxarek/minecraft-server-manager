# История изменений

[English](changelog.md)

## 0.2.1 — 2026-09-24

### Дополнительные изменения

- Кнопка «Убрать из списка» в обзоре заменена на «Удалить». После подтверждения точного пути удаляются вся папка остановленного сервера, включая миры и копии, и профиль. Защищённые и пересекающиеся пути отклоняются; при ошибке удаления профиль восстанавливается. Обновлены руководства на двух языках; проверены сборка, дымовые тесты удаления, запуск WPF и переводы.
- Проверка обновлений теперь использует сохранённый между запусками интервал 15 минут для автоматических и ручных запросов. Повторные и одновременные нажатия используют последний результат; время сброса лимита GitHub или Retry-After продлевает ожидание. Вместо нового запроса кнопка показывает оставшееся время. Добавлены дымовые тесты параллельных запросов, перезапуска и сброса лимита.
- Во вкладке настроек память и путь к Java показываются только для Java-серверов. Простой редактор скрывает параметры другой редакции. Кнопка «Открыть папку» в обзоре открывает Проводник Windows. Проверены сборка, дымовые тесты и запуск WPF.
- Режим игры, сложность и права игроков Bedrock по умолчанию выбираются из списка. Белый список вынесен на отдельную вкладку с добавлением, удалением и включением.
- Добавлена вкладка игроков онлайн с обновлением списка, исключением, управлением правами оператора, блокировкой и разблокировкой Java, добавлением в белый список, сменой режима игры и личными сообщениями.
- После закрытия окна приложение и серверы продолжают работать в трее; там доступен явный выход. Окно запускается развёрнутым.
- Уведомление о создании копии и вкладка копий позволяют показать ZIP в Проводнике. Обновлена документация на двух языках, проверены сборка, дымовые тесты, запуск WPF и ключи переводов.

- Когда сервер не выбран, вместо вкладок показывается просьба создать или выбрать сервер. Убрана дублирующаяся иконка у кнопки создания.
- При создании доступны только редакции с загруженным шаблоном. Путь по умолчанию — `<папка приложения>/<название сервера>`; он меняется с названием до ввода своего пути. При необходимости папка создаётся.
- Добавлены анимированные индикаторы и полосы выполнения при установке серверных файлов, импорте шаблона, создании и восстановлении копии и проверке обновлений.
- Перед текстовым редактором `server.properties` добавлены переключатели и поля для частых и уже существующих параметров; оба редактора используют общее сохранение и проверку несохранённых изменений.
- Установщик показывает найденную версию Java и по выбору загружает Eclipse Temurin JRE 25 с проверкой SHA-256, добавляет её в пользовательский PATH и сохраняет путь для новых Java-профилей.
- Обновлена пользовательская и разработческая документация на двух языках. Проверены запуск WPF-приложения, дымовые тесты, определение Java через Windows PowerShell и пересборка установщика; установка Java на текущем компьютере не запускалась.

### Добавлено

- Сборка установщика через Inno Setup 6: русский и английский языки мастера, установка для текущего пользователя, ярлыки, обновление и удаление. Версия остаётся 0.2.1.
- Локализация приложения на английский и русский языки: английский язык по умолчанию, выбранный язык сохраняется.
- Руководства пользователя и разработчика на английском и русском языках.
- Восстановление мира из выбранной резервной копии с подтверждением и сохранением предыдущего мира до завершения замены.
- Автоматическое создание копий каждые 6, 12 или 24 часа, когда сервер остановлен. Расписание отключено по умолчанию.
- Поиск по тексту консоли с количеством совпадений.
- Состояния запуска, работы, остановки, ожидания перезапуска и ошибки.
- Предупреждение о несохранённых настройках при смене сервера и закрытии приложения.

### Исправлено

- Для Java резервная копия берётся из каталога `level-name` в `server.properties`.
- Ожидающий автоперезапуск отменяется при ручной остановке, удалении профиля и закрытии приложения.
- Создание и восстановление копий, а также импорт и установка серверных файлов выполняются без блокировки окна.
- Чтение консольного буфера синхронизировано с записью; обращения к завершающемуся процессу защищены от гонок.
- При ошибке сохранения параметров прежние значения профиля восстанавливаются.
- Сообщение об успешном создании копии остаётся видимым.
- Файлы нового сервера сначала готовятся во временном каталоге.

### Удалено

- Архивная панель PowerShell/web и её скрипты запуска.

### Проверка сборки

- Пересобран установщик Windows x64 версии 0.2.1 из текущего кода через `Build-Installer.ps1 -ReplaceExisting`; Inno Setup завершился успешно. Проверены наличие файла и хеш SHA-256. Публикации на GitHub не было.
- Выполнена сборка текущего приложения в конфигурации Release через `dotnet build`: предупреждений и ошибок нет. Версия не менялась, установщик и публикация не выполнялись.
- Собран установщик 0.2.1 для Windows x64; проверены тихая установка и удаление.
- Установщик пересобран после изменения интерфейса; проверены запуск установленного приложения на чистом профиле и удаление.
- Установщик 0.2.1 пересобран после возвращения системного выбора файлов и папок, добавления смены языка и иконок. Проверены запуск приложения, иконки всех четырёх вкладок и совпадение ключей переводов.

### Доработка интерфейса

- Выбор файла и папки сервера открывает системный Проводник; остальные формы приложения остаются внутри главного окна.
- В правом верхнем углу панели первого запуска добавлена смена языка; навигация, вкладки и действия получили иконки.
- Окна первого запуска, создания сервера, выбора файлов и папок, а также подтверждения заменены тёмными панелями внутри главного окна.
- Удалены белые поверхности и близкий к белому цвет текста; заголовок окна Windows и иконка приложения оформлены в тёмной палитре.
