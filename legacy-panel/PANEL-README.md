# Локальная панель Minecraft Bedrock

Запуск: дважды щёлкните `Start-Panel.cmd`. Панель откроется по адресу <http://127.0.0.1:8765/> и доступна только на этом компьютере.

Установленный сервер — **Bedrock Dedicated Server 1.26.51.1** для клиента **Minecraft: Bedrock Edition 26.51**. Java Edition с ним несовместима.

Если `bedrock_server.exe` уже был запущен отдельно, панель покажет его состояние, но не сможет отправлять команды в чужое окно. Введите `stop` в старой консоли и затем запустите сервер кнопкой в панели. После этого доступны безопасная остановка, перезапуск, консоль, журнал и резервные копии работающего мира.

Данные панели находятся в `panel/data`, копии миров — в `backups`. При закрытии панели управляемый сервер безопасно останавливается. Системная задача Windows и служба не создаются.
