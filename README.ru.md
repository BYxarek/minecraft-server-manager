# Minecraft Server Manager

[English](README.md) · [Документация](docs/ru/README.md) · [История изменений](changelog.ru.md)

Полная документация: [руководство пользователя](docs/ru/user-guide.md) и [руководство разработчика](docs/ru/developer-guide.md).

Нативное приложение Windows для управления локальными серверами Minecraft Bedrock и Java. Интерфейс написан на WPF и не запускает локальный веб-сервер.

## Возможности

- Окно открывается развёрнутым; после закрытия приложение продолжает работать в трее.
- Отдельная вкладка белого списка, управление игроками онлайн и выбор режима игры, сложности и прав Bedrock из списка.
- Созданную или выбранную резервную копию можно показать в Проводнике.

- Любое количество профилей Bedrock и Java, каждый в выбранной папке и со своим портом.
- Мастер первого запуска со ссылками на официальные загрузки Bedrock и Java. Можно добавить один или оба файла; позже их можно заменить в «Настройках шаблонов».
- Создание серверов из сохранённых шаблонов и подключение уже существующего сервера. Форма предлагает только редакции с загруженными шаблонами и путь `<папка приложения>/<название сервера>`.
- Запуск, безопасная остановка, перезапуск, команды, поиск по журналу, память и состояние процесса.
- Настройка параметров сервера переключателями и полями ввода; ниже доступен редактор `server.properties`. При сохранении создаётся копия `.bak`. Память и путь к Java настраиваются отдельно.
- Индикаторы установки файлов сервера, создания и восстановления копий, импорта шаблонов и проверки обновлений. Без выбранного сервера вместо вкладок показывается подсказка.
- ZIP-копия мира остановленного сервера, восстановление выбранной копии, расписание копирования каждые 6, 12 или 24 часа (когда сервер остановлен), автоперезапуск после сбоя (не более трёх попыток за 5 минут).
- Автоматическая проверка новых версий приложения в [GitHub Releases](https://github.com/BYxarek/minecraft-server-manager/releases) при запуске и по кнопке. Установка обновления остаётся ручной.

## Запуск из исходников

Требуются Windows 10/11 и .NET 10 SDK. Для Java-сервера требуется совместимая Java в `PATH` или путь к `java.exe` в настройках профиля.

```powershell
dotnet run --project src/MinecraftServerManager/MinecraftServerManager.csproj
```

При первом запуске приложение предлагает скачать [Bedrock ZIP](https://www.minecraft.net/en-us/download/server/bedrock) и/или [Java JAR](https://www.minecraft.net/en-us/download/server) с официального сайта и выбрать файлы в форме. Достаточно одного файла для соответствующей редакции. Приложение копирует их в `%APPDATA%/MinecraftServerManager/templates`; сменить файлы можно через кнопку «Настройки шаблонов». Новые профили получают копию выбранного шаблона, уже созданные серверы при смене шаблона не меняются. Локальная папка `deffolt-minecraft-server` не используется автоматически.

Для нового Java-сервера приложение создаёт `eula.txt` с `eula=false`. Прочитайте [Minecraft EULA](https://www.minecraft.net/en-us/eula) и, если принимаете её, измените значение на `eula=true` перед запуском. Профили хранятся в `%APPDATA%/MinecraftServerManager/servers.json`, миры и копии остаются в выбранных папках.

По умолчанию интерфейс работает на английском языке. Переключить его на русский можно в боковой панели; выбор сохраняется в `%APPDATA%/MinecraftServerManager/settings.json`.

## Сборка версии

```powershell
pwsh ./scripts/Build-Release.ps1
pwsh ./scripts/Build-Installer.ps1
```

Первая команда собирает переносимый ZIP, вторая — установщик Windows через Inno Setup 6. Установщик показывает обнаруженную версию Java и по выбору загружает Eclipse Temurin Java 25 для текущего пользователя, добавляет её в пользовательский PATH и сохраняет путь в приложении. Файлы появляются в `dist`. Версия задаётся в `src/MinecraftServerManager/MinecraftServerManager.csproj` в свойстве `Version`; изменения записываются в [`changelog.ru.md`](changelog.ru.md). Публикация GitHub Release выполняется отдельно. GitHub Actions в проекте не используются.
