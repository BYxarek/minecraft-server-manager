# Руководство пользователя

[English](../user-guide.md)

Minecraft Server Manager 0.2.1 — приложение для Windows 10/11, которое запускает и контролирует локальные серверы Minecraft Bedrock и Java. Серверные файлы скачиваются пользователем отдельно; приложение не включает их в комплект.

## Что потребуется

- Для Bedrock: ZIP официального Bedrock Dedicated Server.
- Для Java: JAR сервера и совместимая Java в `PATH` либо путь к `java.exe` в настройках профиля.
- Для запуска из исходников: .NET 10 SDK. Готовый архив релиза содержит приложение с необходимой средой .NET.

Ссылки на загрузки доступны в панели первого запуска и в «Настройках шаблонов»: [Bedrock](https://www.minecraft.net/en-us/download/server/bedrock), [Java](https://www.minecraft.net/en-us/download/server). Формы и подтверждения открываются внутри главного окна приложения. Кнопки «Выбрать» и «Обзор» открывают системный Проводник для выбора файла или папки сервера. Ссылки на официальные загрузки открываются в браузере.

## Установка и удаление приложения

Запустите `MinecraftServerManager-v0.2.1-win-x64-setup.exe` на Windows 10/11 x64. Мастер доступен на русском и английском языках, устанавливает приложение для текущего пользователя без прав администратора, создаёт ярлык в меню «Пуск» и по выбору — на рабочем столе. После установки приложение можно запустить из мастера. Перед обновлением закройте приложение, чтобы работающие серверы завершились корректно. Удаление доступно через «Установленные приложения» Windows. При удалении сохраняются `%APPDATA%\MinecraftServerManager` и выбранные вами папки серверов, включая миры и резервные копии.

Установщик показывает, найдена ли Java, её версию и путь к исполняемому файлу. Если планируете создавать серверы Java Edition, выберите установку Eclipse Temurin Java 25. Установщик скачает среду выполнения Java 25, проверит SHA-256, разместит её в `%LOCALAPPDATA%\MinecraftServerManager\Java25`, добавит каталог `bin` в PATH текущего пользователя и сохранит путь для приложения. Для этого пункта нужен интернет; само приложение можно установить без Java. При удалении приложения Java остаётся установленной.

## Первый запуск и шаблоны

1. Откройте приложение. Если шаблонов ещё нет, в главном окне появится панель выбора серверных файлов.
2. Скачайте нужный сервер с официального сайта и выберите ZIP Bedrock, JAR Java или оба файла.
3. Нажмите «Сохранить файлы». Приложение скопирует их в `%APPDATA%\MinecraftServerManager\templates`.

Можно нажать «Позже»: уже существующий сервер по-прежнему можно подключить. Для создания нового сервера соответствующий шаблон понадобится добавить через «Настройки шаблонов». Замена шаблона влияет только на новые серверы; файлы уже созданных серверов не обновляются.

По умолчанию интерфейс работает на английском языке. Кнопка смены языка есть справа сверху на панели первого запуска; язык также можно переключить в боковой панели. Выбор сохранится для следующего запуска.

## Создать или подключить сервер

### Новый сервер

1. Нажмите «Создать сервер». Если сервер не выбран, вместо вкладок в основной части окна отображается просьба создать или выбрать сервер.
2. Укажите название, редакцию, папку и порт. Доступны только редакции с загруженным шаблоном. Изначальный путь — `<папка установки приложения>/<название сервера>`; он меняется вместе с названием. Если указать или выбрать свой путь, дальнейшее переименование его не затронет.
3. Нажмите «Создать». Приложение создаст папку, если её нет, и скопирует в неё серверные файлы. Во время установки отображается индикатор выполнения.

Для нового Java-сервера создаётся `eula.txt` со значением `eula=false`. Прочитайте [Minecraft EULA](https://www.minecraft.net/en-us/eula). Если принимаете условия, откройте `eula.txt` в папке сервера и измените значение на `eula=true` перед запуском.

### Существующий сервер

Нажмите «Подключить папку», выберите редакцию, папку и порт. В корне папки должен находиться `bedrock_server.exe` для Bedrock или `server.jar` для Java. Подключение добавляет профиль в приложение и не копирует серверные файлы.

Папку нельзя подключить дважды. Для профилей одной редакции нельзя указать одинаковый порт. Адрес `127.0.0.1:порт` в обзоре предназначен для подключения с этого же компьютера; приложение не настраивает сеть или брандмауэр.

## Запуск, остановка и консоль

- «Запустить» запускает процесс выбранного сервера. Статус показывает запуск, работу процесса, остановку, ожидание перезапуска или ошибку. «Процесс запущен» означает, что процесс работает; готовность игрового сервера смотрите в его журнале.
- «Остановить» отправляет команду `stop`. Если сервер не завершится за 30 секунд, приложение завершит процесс принудительно.
- «Перезапустить» сначала останавливает сервер, затем запускает его снова.
- «Открыть папку» во вкладке «Обзор» открывает каталог выбранного сервера в Проводнике Windows.
- Во вкладке «Консоль» можно отправлять команды и искать текст журнала. Поиск показывает число совпадений и переводит просмотр к первому совпадению.

Консоль содержит журнал текущего сеанса приложения: после закрытия приложения её содержимое не сохраняется. Закрытие окна сворачивает приложение в область уведомлений: серверы и резервное копирование продолжают работать. Чтобы вернуть окно, дважды нажмите значок в трее или выберите «Показать окно». Пункт «Выход из приложения» останавливает запущенные серверы и завершает программу после файловых операций. При запуске окно развёрнуто на весь экран.

## Настройки профиля и `server.properties`

Поля памяти и пути к Java отображаются только у Java-сервера. Простой список параметров скрывает настройки, относящиеся только к другой редакции. Расширенный текстовый редактор по-прежнему показывает весь файл `server.properties`.

Во вкладке «Настройки» можно изменить имя сервера, порт, максимальную память Java, путь к Java и автоперезапуск. После изменения нажмите «Сохранить параметры». Порт в `server.properties` обновится вместе с профилем. Память Java должна быть от 512 до 131072 МБ; на Bedrock этот параметр не влияет.

Новые Java-профили автоматически используют путь к Java 25, сохранённый установщиком, если файл доступен. Для каждого профиля путь можно изменить отдельно. Ниже основных полей параметры `server.properties` представлены переключателями и полями ввода; режим игры, сложность и права игроков Bedrock по умолчанию выбираются из списка; здесь же доступны остальные ключи уже существующего файла. Нажмите «Сохранить параметры сервера», чтобы записать их. Ещё ниже остаётся текстовый редактор файла для опытных пользователей. Обе кнопки сохранения записывают один и тот же файл и создают копию `.bak`. Сохраните параметры файла до изменения основных параметров профиля.

Файл `server.properties` редактируется отдельно в нижней части вкладки. Нажмите «Сохранить server.properties»; предыдущая версия файла останется рядом с расширением `.bak`. Если вы меняете порт, используйте поле «Порт» профиля: приложение не позволит сохранить в `server.properties` другое значение `server-port`.

При импорте серверных файлов, создании сервера, создании и восстановлении копии мира и проверке обновлений показываются анимированные индикаторы. Если объём работы нельзя определить заранее, полоса показывает выполнение операции без процента.

Изменения `server.properties` применяются сервером после перезапуска. Если в полях есть несохранённые изменения, приложение спросит о них при смене сервера или выходе через трей.

Автоперезапуск после неожиданного завершения ограничен тремя попытками за пять минут с паузой три секунды между завершением и новым запуском. Кнопка «Остановить», удаление профиля или закрытие приложения отменяют ожидающий перезапуск.

## Игроки и белый список

Во вкладке «Игроки онлайн» приложение запрашивает команду `list` и обновляет список примерно раз в 10 секунд, пока открыта вкладка. Выберите игрока, чтобы исключить его, выдать или снять права оператора, добавить в белый список, сменить режим игры или отправить личное сообщение. На Java также доступны блокировка и разблокировка по имени. Команды работают для сервера, запущенного из приложения. Остальные команды доступны во вкладке «Консоль».

Во вкладке «Белый список» можно включить ограничение входа, посмотреть `whitelist.json` (Java) или `allowlist.json` (Bedrock), добавить и удалить имена. На работающем сервере изменения выполняются его командами. На остановленном сервере Bedrock позволяет добавлять и удалять имена, Java — удалять. Для добавления имени Java-сервер нужно запустить: он определит UUID игрока. Перед прямым изменением файла сохраняется `.bak`.

## Резервные копии и восстановление

### Создать копию вручную

1. Остановите сервер.
2. Нажмите «Создать копию мира» в обзоре или во вкладке «Копии и файлы».
3. Дождитесь сообщения с путём ZIP-архива. Нажмите «Показать в Проводнике» в уведомлении или выберите архив во вкладке «Копии и файлы» и нажмите такую же кнопку.

Архивы сохраняются в `<папка сервера>\backups`. Для Java копируется каталог мира из параметра `level-name` в `server.properties` (по умолчанию `world`); для Bedrock копируется каталог `worlds`. Если мир ещё не создан, приложение покажет ошибку. Копии хранятся на том же диске, что и сервер, поэтому для защиты от поломки диска перенесите важные архивы в другое место самостоятельно.

### Автоматические копии

Во вкладке «Копии и файлы» выберите «Каждые 6 часов», «Каждые 12 часов» или «Каждые 24 часа». По умолчанию расписание выключено. Приложение проверяет его примерно раз в минуту **пока приложение работает, в том числе в трее** и создаёт копию только когда сервер остановлен. Если срок наступил во время работы сервера, копия будет создана после его остановки при очередной проверке. При ошибке следующая попытка произойдёт не ранее чем через час. Автоматическое удаление старых ZIP-архивов не предусмотрено.

### Восстановить мир

1. Остановите сервер и выберите ZIP в списке вкладки «Копии и файлы».
2. Нажмите «Восстановить выбранную» и подтвердите замену текущего мира.
3. Дождитесь сообщения об окончании, затем запустите сервер.

Восстановить через интерфейс можно архив из папки `backups` данного сервера. Во время замены приложение временно сохраняет текущий каталог мира для отката при ошибке, а после успешного восстановления удаляет его. Если текущий мир нужен отдельно, сначала создайте его копию.

## Обновления и удаление профиля

Проверка обновлений отправляет не больше одного запроса GitHub за 15 минут, в том числе после перезапуска приложения. Повторное нажатие показывает, когда можно проверить снова, и использует предыдущий результат. Если GitHub указывает более долгий срок ограничения, приложение ждёт до его окончания.

Приложение проверяет новые версии при запуске и по кнопке «Проверить обновления». При наличии новой версии откроется страница GitHub Release; установка выполняется вручную. Обновление приложения не заменяет файлы серверов Minecraft.

«Удалить» во вкладке «Обзор» безвозвратно удаляет профиль и всю папку сервера: миры, резервные копии и остальные файлы внутри неё. Сначала остановите сервер. В подтверждении показан точный путь. Папку, которая пересекается с папкой другого сохранённого сервера или содержит приложение либо системный каталог, удалить нельзя. Если удаление завершится ошибкой, профиль восстанавливается для проверки папки и повторной попытки.

## Частые проблемы

| Сообщение или ситуация | Что проверить |
| --- | --- |
| Нет шаблона для редакции | Добавьте ZIP Bedrock или JAR Java через «Настройки шаблонов». |
| Не найден `bedrock_server.exe` или `server.jar` | Проверьте папку профиля и наличие файла в её корне. |
| Java требует `eula=true` | Прочитайте EULA и при согласии измените `eula.txt` в папке сервера. |
| Java не запускается | Проверьте установленную Java и путь к `java.exe` в настройках профиля; причину запуска также ищите в консоли. |
| Копия мира не создаётся | Остановите сервер и убедитесь, что каталог мира уже существует. |
| Автоматическая копия не появилась | Проверьте, что приложение открыто, сервер остановлен и для профиля выбран интервал. |
| Ошибка проверки обновлений | Проверьте доступ к GitHub; серверы можно использовать без этой проверки. |
